## Architecture / proposed approach
Create a separate Vite React + TypeScript static site under `/home/soham/JevBlog`, entirely outside the Saarthi repository. Build it from small article sections, a semantic comparison table, accessible custom diagrams, and locally bundled assets, with claims supported by verified public sources or repository evidence. Use Motion only for explanatory reveals and restrained pipeline emphasis; preserve native scrolling, keep all content readable without animation, avoid long pinned sequences, disable parallax on mobile, and respect reduced-motion preferences.
