# Jev Notes

A frontend-only explainer about Jev, TypeSafe's System One decision model, its published RLCD training objective, and how decision models differ from generative LLMs. The article ends with a short user-provided hackathon anecdote.

## Run locally

```sh
npm ci
npm run dev
```

## Verify

```sh
npm test
npm run lint
npm run build
```

This is a static Vite site with no backend or API keys. Source citations are linked in the article. Jev and Laya training details are attributed to their publishers; undisclosed details are explicitly left unknown. Scroll effects honor reduced-motion preferences and degrade to readable static content.

## Deploy

Set the Vercel project root to this directory, build command to `npm run build`, and output directory to `dist`. No deployment has been performed yet.
